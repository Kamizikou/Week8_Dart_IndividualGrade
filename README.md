# PC16 – Week 8: Dart Logic Problem Set

This repository contains the Dart solution for **Week 8: Dart Programming Fundamentals (Part 2)** under the course **PC16 - Mobile Development with Lab** at National Teachers College.

---

## Overview
This program demonstrates core Dart logic constructs by combining conditional branching, loops, modular functions, and runtime error handling inside a unified grade-processing utility.

---

## Features & Rubric Alignment

- **Conditional Logic (`if / else`):** Evaluates score ranges to classify student performance into distinct outcome tiers.
- **Loops (`for`):** Iterates through a dataset of raw inputs sequentially.
- **Functions & Parameters:** Enforces modularity through `processStudentScores(List<String> rawScores)`, taking a input list and returning the calculated total score.
- **Error Handling (`try / catch`):** Handles `FormatException` (invalid non-numeric strings) and `ArgumentError` (out-of-bound values) gracefully without crashing the execution flow.

---
